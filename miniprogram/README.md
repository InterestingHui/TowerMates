# TowerMates 小程序壳（B 路线：web-view 嵌 H5）

把已上线的 H5 装进微信里。**不改玩法、不改数值**，只负责打开那一页。

## 三个前置条件（缺一不可，且第 2 条是硬阻塞）

1. **小程序 AppID**：填进 `project.config.json` 的 `appid`。目前是空的，微信开发者工具会提示补。
2. **业务域名**（web-view 只能打开已校验的域名）：
   需要把一个微信给的校验文件放到该域名的**根目录**，且域名已备案。
   ⚠️ 现在的 H5 挂在 `towermates.app.workbuddy.host`（托管域名），**根目录文件我们放不进去**
   → 必须准备一个自己的已备案域名，反代到这份 H5，再把那个域名配成业务域名。
   这一步的时间成本主要是**域名备案**（通常 1–20 个工作日），不是写代码。
3. **类目与自审**：工具类目即可（不涉及支付），按平台要求提交截图与说明。

## 用法

1. 微信开发者工具 → 导入本目录 → 填 AppID。
2. 后台「开发管理 → 开发设置 → 业务域名」添加自己的域名，下载校验文件放到域名根目录，
   确认 `https://你的域名/校验文件名.txt` 可直接访问。
3. 把 `pages/index/index.js` 顶部的 `H5` 换成 `https://你的域名/?sharecode=U7XMLC2NKJ`
   （sharecode 是访问凭证，不能省）。
4. 真机预览：确认能进塔、能点、能听到声音。

## 已经踩到/要留意的坑

- **sharecode 必需**：裸域名返回 403，链接里必须带查询参数。
- **音频**：iOS 下 web-view 内音频需用户手势后才播（首次点击塔门即满足，不要在自动播放上抱期待）。
- **全屏**：web-view 上方会保留原生导航栏，游戏内 HUD 已按 900px 高设计，进 web-view 后会略微压缩，
  真机上要复看一遍顶部 HUD 是否被挡。
- **分享**：web-view 内的页面不能直接调 `wx.shareAppMessage`，分享按钮要用小程序的 `onShareAppMessage` 在外面做。
- **返回**：安卓物理返回键会退出 web-view，需要时可监听 `onBackPress` 给二次确认。

## 为什么只做到这一步

上面第 2 条（业务域名备案）不是代码问题，是账号与合规问题。壳先备好，等域名和 AppID 到位，
填两个值就能提审——不用再改代码。
