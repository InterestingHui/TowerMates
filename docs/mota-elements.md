# 魔塔品类元素调研 · 与本作的对照（2026-11-12）

> 目的：把「经典魔塔做得好的元素」逐条列清，与本作逐项对照，只补真正缺的、且不破坏现有构筑的。
> 调研口径：经典 50 层魔塔的道具体系、魔塔 Wiki 的怪物特殊属性表、h5mota 广场的设计哲学、以及品类评论里反复出现的「为什么好玩」。

---

## 一、结论先行

魔塔的乐趣不是「打怪升级」，而是**在固定数值下做资源分配**——每一把钥匙、每一点攻防、每一次绕路都是可计算的取舍。
玩家真正在玩的是一个**带格点的线性规划题**。

按这个标准，本作已有的系统（塔规、锁环、格挡、祭坛、路障式 Boss）都在服务同一件事，**唯一的结构性缺口是：怪物全是白板**。
17 只怪只有 HP/攻/防，于是「加攻还是加防」在本作里没有答案——反正加什么都一样。
**这一条补上，魔塔的算题感才真正成立。**

## 三、本轮落地（4 项）

### 3.1 怪物特性系统（核心）

数据层 `trait` 字段，引擎 `predictBase` 统一结算，图鉴/速查卡/战斗面板三处暴露。

| 怪 | 特性 | 设计意图 |
|---|---|---|
| 蝙蝠（1 层） | ⚡ 先攻 | 第一只怪就教会「战斗不是零成本」 |
| 怨灵（4 层） | 🔮 魔攻 | 第一次让「堆防御」失效 |
| 狼人（5 层） | ⚔️ 连击 | 第一次让「堆防御」双倍划算 |
| 锈犬（7 层） | ⚔️ 连击 | 后期复现，防止只教一次 |
| 无面者（11 层起） | 🔮 魔攻 | 后期复现 |

数值口径：特性不是白送伤害，而是**改变相性**。
- 连击怪的攻击力同步下调（狼人 71→52、锈犬 92→72），等效伤害不变，但每点防御的收益翻倍。
- 魔攻怪的攻击力压到「穿防后 ≈ 同级普通怪」（怨灵 57→42、无面者 106→64），否则无视防御会直接打穿曲线。

### 3.2 图鉴相性面板

每只怪多一行：`攻 +1 省 X 血 · 防 +1 省 Y 血`。
只给边际收益，不给结论——「该加什么」仍由玩家判断，这是魔塔的乐趣所在。

实测差异（初始属性下）：
- 怨灵（魔攻）：攻 +1 省 342 血 / **防 +1 省 0 血**
- 僵尸（普通）：攻 +1 省 25 血 / 防 +1 省 7 血
- 狼人（连击）：防的收益是同级普通怪的两倍

### 3.3 旧十字架（遗物）

对`亡`类（骷髅、僵尸、怨灵、吸血鬼、提灯僧、灰烬祭司…）伤害 ×1.5。
本作早就有 `kind` 分类（兽/异/亡/构/魂/锁）但从未被使用——这次终于让它有意义。

### 3.4 幸运金币（遗物）

战斗金币 ×2，与「贪婪」誓约（×1.7）叠乘。给「经济流」一条真实存在的最优路线。

两件新遗物都进第 3 层祭坛池（5 → 7 件），不新开系统。

## 四、明确不做的（附理由，避免以后重复讨论）

| 元素 | 为什么不做 |
|---|---|
| 破墙镐 / 地震卷轴 | 本作地图是手工设计的 11×11 小格，自由破墙会直接击穿关卡设计（每个隐藏物都靠墙的位置卡节奏）。已有「层阶之钥封印两件宝物」承担同类取舍。 |
| 炸弹 / 圣锤清怪 | 会绕过「打不过就变强」的核心循环，让数值失去意义。卡关已有三个出口：回城补给、祭坛、层阶之钥开层。 |
| 中毒 / 领域 / 自爆 / 仇恨 | 需要「状态系统」与「战后结算」两套新管线，且会与本作的「撞怪即战 + 自动演出」节奏冲突。收益是压力，成本是一整套新 UI。 |
| 模仿 / 潜伏 / 伪装 | 会破坏「窥探之镜 = 情报价值」的付费逻辑（情报本身在本作是商品）。 |
| 坚固（已支持未启用） | 数学上要求极低血量（回合数 = 血量），需要新增专门的低血高防怪 + 改地图。留作下一轮的「防御检测关」。 |
| 圣水改按攻防加成 | 现有固定 900 的版本已进入平衡，改成浮动会牵动全局曲线，收益不抵风险。 |
| 三色钥匙 | 用户在 v0.3.6 明确要求简化为黄/红两色，不回退。 |
