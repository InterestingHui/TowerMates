# 塔的长度：为什么第一座只有 3 层，以及怎么加

> 2026-11-28 17:2x。现状：4 座塔（锈 / 灰 / 钟 / 无名），前三座各 3 层，主塔 13 层，共 22 层。
> 本文只谈「长度」和「层数露底」，不改数值、不改地图。

---

## 1. 为什么第一座只有 3 层

不是缩水，是「齿」的规格。三座齿塔的结构是固定的三拍：

| 层 | 角色 | 内容 |
|---|---|---|
| 1 | 门厅 | 教学：本塔的第一只杂兵、第一把钥匙、第一件装备 |
| 2 | 齿槽 | 岔路：一扇黄门 + 一瓶药 / 一件装备 |
| 3 | 齿 | Boss 堵住唯一上楼口，打倒 → 塔门结算 → 塔印 |

三座塔分别是 1000/10/10、1200/14/12、1400/18/16 起步，独立成长，只带走塔印。
所以 3 层是**完整的**——它是一枚齿，不是一座塔。

问题出在**叫法**：hub 上写「锈塔 · 第一枚齿」，卡片又写「3 层」。玩家按「塔」的预期进来，3 层就显得像半成品。

## 2. 两条路

### A. 改预期（便宜，当天可做）

- 卡片不写层数（见 §4）；
- 把「锈塔 / 灰塔 / 钟塔」在 UI 上统一读成「第一枚齿 · 锈 / 第二枚齿 · 灰 / 第三枚齿 · 钟」，主塔才叫「塔」；
- 3 层作为「齿」就成立了，不需要加内容。

### B. 改长度（贵，单独一轮）

每座齿塔 3 → 5 层，五拍：

| 层 | 角色 | 新增内容建议 |
|---|---|---|
| 1 | 门厅 | 不动 |
| 2 | 齿槽 | 不动 |
| 3 | **井道（新）** | 资源岔路：1 扇黄门 + 1 只精英 + 1 瓶药；教「钥匙换资源」 |
| 4 | **齿室（新）** | 尖峰 + 本塔签名物（攻/防宝石各一），打完正好进 Boss |
| 5 | 齿 | Boss 不动（可 +10~15% HP 抵消新增层的成长） |

总量：22 → 28 层（3 座 × 5 + 13）。

#### 结构代价（必须先算清）

1. `floors` 是**扁平索引**：0–12 主塔，13–21 三座齿塔。插 2 层/塔会让灰塔、钟塔整体后移，`towers[].floors` 全部要改。
2. `progressNo` 现在写死 `(order-1)*3 + floorNo`，必须改成**按塔累计**（锈 1–5、灰 6–10、钟 11–15、主 16–28）。
3. 旧档 / 榜单 / 挑战码存的是扁平 `floor`，插层后旧记录的层号会错位——15:3x 刚做过一次 22 层口径迁移，这次要做第二次，且要加版本标记（一次迁移只能扛一次变更）。
4. 门禁：`check.js` 现在断言「齿塔 3 层 / 主塔 13 层」「塔群覆盖 22 层」；`engine-test` 也断言 `D.floors.length === 22`。全部要跟着改。
5. 平衡：每塔多 2 层 ≈ 多 2 只杂兵 + 1 件装备 + 1 瓶药。Boss 7/8/9 的 TTK 会掉一档，需要重跑三座塔的单塔模拟（目前 sim 只跑主塔）。

**建议**：B 单独开一轮「多塔 2.0」，先只做锈塔 3→5 试点，跑通迁移与平衡，再复制到灰/钟。

## 3. 顺手查到的两个「层数」问题

### 3.1 层阶之钥会露全塔，还能跳最终层（严重）

- `openGate()` 用全局 `i + 1` 列 0..max，并写「塔共 22 层」——把整座塔的目录摊开。
- `visitedMax()` 读全局 `flags.maxFloor`。拔完三枚齿后 `maxFloor = 21`，进主塔拿 Q 后，主塔 13 层全被算成「走过」——**能从第 1 层直接跳到碑魔**。
- `jumpTo()` 不校验目标是否在当前塔，**还能跳进别的齿塔**。

修法（约 20 行）：

1. `flags.towerMax = { [towerId]: maxFloorInTower }`，`changeFloor` / `enterTower` 维护；
2. `visitedMax()` 只读当前塔的 `towerMax`；
3. `jumpTo()` 加 `D.towerOf(target).id !== D.towerOf(s.floor).id → refuse`；
4. `gateForth()` 的 target 上限改成「当前塔的最后一层」，不是 `D.floors.length`；
5. `openGate()` 只列 `D.towerOf(s.floor).floors`，不写总数。

### 3.2 UI 三处露层数

| 位置 | 现文 | 改成 |
|---|---|---|
| 塔群卡片 `main.js` `<em>` | `3 层 · 守门 锈齿` | `守门 · 锈齿` |
| 楼层卡 `showFloorCard` | `第 1 / 3 层` / `第 1 层 / 共 13 层` | `第 1 层` |
| 层阶之钥面板 `openGate` | `塔共 22 层` | 不写总数 |

## 4. 立即补丁（3 处文案）

等并行会话落地后改；行号会漂，按代码片段找。

**① 楼层卡**（`showFloorCard`）：

```js
// 旧
$('fcNum').textContent = ch
  ? `${ch.title} · ${D.floorNo(floor)}/${tw.floors.length} 层`
  : (tw.main
    ? `第 ${D.floorNo(floor)} 层 / 共 ${tw.floors.length} 层`
    : `${tw.name} · 第 ${D.floorNo(floor)} / ${tw.floors.length} 层`);
// 新
$('fcNum').textContent = ch
  ? `${ch.title} · 第 ${D.floorNo(floor)} 层`
  : (tw.main ? `第 ${D.floorNo(floor)} 层` : `${tw.name} · 第 ${D.floorNo(floor)} 层`);
```

**② 塔群卡片**：

```js
// 旧
<em>${t.floors.length} 层${boss ? ' · 守门 ' + boss.name : ''}</em>
// 新
<em>${boss ? '守门 · ' + boss.name : '塔门已开'}</em>
```

**③ 层阶之钥面板**：

```js
// 旧
const hidden = D.floors.length - (max + 1);
if (hidden > 0) rows.push(`...<b>未到过 · ${hidden} 层</b><small>... · 塔共 ${D.floors.length} 层</small>...`);
// 新
if (max + 1 < D.floors.length) rows.push(`...<b>未到过</b><small>往上走才会亮</small>...`);
```
