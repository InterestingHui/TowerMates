# TowerMates · 魔塔 v2.1

一个可直接在浏览器里玩的魔塔（固定数值 RPG）：**12 层主塔 + 1 层隐藏「锁芯」**，四章剧情、四位锁匠 Boss、双结局、八件常规遗物、三座祭坛，以及 v2.1 的**章末回响与 16 枚锁环构筑**。纯前端、零依赖、数据驱动。

**线上版**：<https://towermates.app.workbuddy.host/?sharecode=U7XMLC2NKJ&play=1> —— 点击直接落到第 1 层可操作地图；去掉 `&play=1` 则走开始界面与四选一誓约。`sharecode` 是访问凭证，不能省略。

发布目录 `publish/`。每次改完代码先跑 `node tools/sync-publish.js`（把源码同步到 publish/，并把静态资源版本号换成内容指纹 `?v=<build>`），再用应用发布能力部署 `publish/`。入口链接永久不变，代码一更新资源 URL 自动变化，浏览器必然加载新版本。

## 运行

```bash
node tools/serve.js 8799 .     # 或 python -m http.server 8799
# 打开 http://127.0.0.1:8799/index.html
```

直接双击 `index.html` 也能玩。

## 操作

- `↑↓←→` / `WASD` 走一格（长按连走）；点击格子自动寻路，路上被怪挡住会走过去开打。
- 撞上怪物即战斗（自动演出，可点击跳过）；打不过会被拦住，不会送死。设置里可开「快速战斗」把演出压到 42% 时长。
- 对白：点击 / 空格 / Enter 继续，`←` 上一句，`Esc` 跳过本段。
- 章末锁环三选一：点卡片，或按 `1` / `2` / `3`。
- 触屏：在地图上滑动走一格，连续滑动可连走；底部虚拟方向键长按连走。
- 层阶之钥：第 1 层可得，点遗物栏的钥匙跳到走过的楼层；**头一次**还能往前开一层，代价是那一层两件最好的东西被封印（锁匠守着的章末层不能绕）。
- 挑战码：通关生成，含层数 / 用时 / 塔印 / 塔规数；把朋友的码贴进名录，就能比谁爬得更高、更快。
- 右上角：🔮 图鉴（买镜后）、🏆 榜单、⚙ 设置（特效/音效/音乐/震动/快速战斗/重来本层）。

## 四章与四位 Boss

| 章 | 层 | 主题 | Boss | Boss 层 | 锁 |
|---|---|---|---|---|---|
| 第一章 · 刻痕 | 1–3 | 规矩与计数 | 砚（第二位工匠） | 3 | 名册之锁 |
| 第二章 · 明塔 | 4–6 | 真相与代价 | 炬 / 魔王（第一位工匠） | 6 | 炉心之锁 |
| 第三章 · 塔脊 | 7–9 | 被删掉的六层 | 铎（第五位工匠） | 9 | 时辰之锁 |
| 第四章 · 无名 | 10–12 | 名字的重量 | 衡（第六位工匠） | 12 | 无名之锁 |
| 终章 · 锁芯 | 13（隐藏） | 谁来续锁 | —（三精英 + 塔心石） | — | 锁芯 |

- 每位 Boss 都横在该层上楼的**唯一通路**上：叙事上是锁的守护者，玩法上就是那道门闩。
- 第 6 层是旧版塔顶，现在只是中点：打完炬，王座后露出窄梯，塔翻到另一半「锁梁」。
- 第 12 层打完衡，才能走到公主与隐藏窄梯；塔规 ≥8 条时，塔顶后开「锁芯」。

详细设计（主题、剧情节点、Boss 放置理由、难度曲线、实现映射）见 [`docs/tower-12-chapters.md`](docs/tower-12-chapters.md)。

## 剧情

- **序章 6 句**：灰港镇十年送一人进塔，今年是你；公主同夜失踪；镇上的人说塔只有六层。
- **烛 ×5 段**：1 层（初遇）、4 层（密道）、5 层（狼厅幽灵格）、7 层（锁梁）、11 层（刻名室前）。逐步揭开锁身/锁梁、钟与账期、第六个名字。
- **秤 ×2 段**：第 3 层的军需官；第 8 层留下一副无人货摊。
- **工匠手记**（4 层）：有它才能在塔顶做**显式抉择**。
- **断剑**（5 层）：第八位勇者的遗物，拾取触发旁白，同时是「断刃之锋」。
- **双结局**：「铁与霜」（让她续锁）/「第六个名字」（念出烛的名字）。

## 系统

| 系统 | 说明 |
|---|---|
| 遗物 | 8 件常规：守誓之盾 / 断刃之锋 / 余烬灯芯 / 鸦的铁腕 / 岚的账本 / 磐的灯油 / 无名之镜 / 层阶之钥；另有塔心石 |
| 祭坛 | 第 3 层三选一、第 5 层二选一、第 8 层二选一（「八个人的行李」），一局最多三件 |
| Boss 战 | 四位章节 Boss 各有三阶段过场（66% / 33% 血量），只改表现不改数值 |
| 隐藏层 | 塔规 ≥8 且击败衡后，塔顶后开窄梯进「锁芯」：三精英 + 塔心石二选一 |
| 路遇 | 每层一个 `?` 点；1–3 层 6 个浅层事件，4–6 层 6 个深层事件，7 层起 8 个锁梁事件，共 20 个；部分选择留下通关余烬 |
| 名录 | 塔友名录按誓约分五档（全部/不立誓/慈悲/贪婪/铁壁），按「爬到多深 → 是否真结局 → 用时」排序；贴朋友的挑战码会出现幽灵行 |
| 余烬 | 通关时按结局、塔规、章印、塔心、路遇、誓约与锁环直接累加，只用于解锁誓约，不卖战力 |
| 誓约 | 开局六选一，改整局规则；越难走的誓约通关余烬越多（+0 ~ +9）；苦行 / 无名两条要用余烬解锁 |
| 格挡 | 每层一次：战斗中点一下，这一场承伤 ×0.6（装「断刃之环」后 ×0.5）；Boss 层建议留给 Boss |
| 层阶之钥 | 第 1 层可得；点遗物栏的它，在走过的楼层之间跳（回城补给的核心） |
| 音乐 | 每层一段 4–5 音旋律动机，叠在低频垫音上；设置里「环境音乐」独立开关 |
| 塔心石 | 锁芯中央二选一：带走（生命上限 +300）或放下（通关余烬 +3）；两种后日谈 |
| 塔规 | 12 层各一条可选目标（少杀/开门/不花钱/打精英/清层/半血收尾）；顶栏实时显示达成状态，离开该层时结算，达成的规矩决定塔印并留下余烬 |
| 章末回响 | 章末 Boss 倒下时结算该章 3 条塔规：做到 2 条以上留 1 枚章印并解锁锁环三选一；章印计入塔印与余烬，结算即锁定 |
| 锁环 | 4 章 × 6 枚 = 24 枚，每章随机抽 3 选 1；只改规则/资源/信息（回血、物价、格挡比例、余烬、门槛），不直接加攻防 |
| Boss 台词池 | 每位锁匠的阶段过场每局从 2×2 池里抽一组，同一局固定、换一局不同 |
| 塔印 | 四档（无痕 / 守灯 / 留名 / 未竟），由真结局、塔规、章印、是否回头判定；结算页写明离下一枚塔印还差什么。**没有结算分** |
| 商店 | 第 3 层秤、第 8 层无人货摊：黄/红钥匙、红药水、力量训练、护甲强化、余烬灯芯、窥探之镜；攻防训练每次涨价 20 |
| 窥探之镜 | 100 金一次性：地图标出每只怪的预计损失，解锁图鉴 |
| 成就 | 31 项，localStorage 持久化，吐司通知 |
| 软锁兜底 | 每层入口快照，设置里「重来本层」 |
| 快速战斗 | 设置独立开关；战斗演出整体压到 42%，命中/格挡/阶段过场同步缩短 |
| 存档 | `towermates_save_v3`，`ver:5`；v2.1 新增字段在读取时补默认值，老档继续可用 |

## 核心规则

- 先手战斗：`回合 = ceil(敌HP ÷ (我攻−敌防))`，承伤 `= (回合−1) × max(0, 敌攻−我防)`；守誓之盾再乘 0.88。
- 演出与结算共用 `Engine.fightDamage()`：誓约减伤、停钟之环、格挡只算一次，血条落点与实际扣血一致。
- 攻 ≤ 敌防 → 无法破防；预计承伤 ≥ 当前生命 → 拒绝移动。
- 升级：攻 +3、防 +2、生命 +130（有灯油再 +80），上限 Lv.19，阈值见 `levelExp`。
- 钥匙两色；幽灵格是剧情锚点，不战斗。
- 首次挑战章节 Boss 先播对白，再自动开战；Boss 死亡后播该章收束。
- 第 12 层 Boss 战前记得留格挡；塔规 ≥8 才有隐藏层。
