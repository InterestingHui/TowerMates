# TowerMates · 魔塔 v2.2

一个可直接在浏览器里玩的魔塔（固定数值 RPG）：**12 层主塔 + 1 层隐藏「锁芯」**，四章剧情、四位锁匠 Boss、双结局、八件常规遗物、三座祭坛，以及 v2.2 的**章末回响与 24 枚锁环构筑**。纯前端、零依赖、数据驱动。

**线上版**：<https://towermates.app.workbuddy.host/?sharecode=U7XMLC2NKJ&play=1> —— 点击直接落到第 1 层可操作地图；去掉 `&play=1` 则走开始界面（首局是 1 张确认卡，第 2 局起四选一誓约）。`sharecode` 是访问凭证，不能省略。

发布目录 `publish/`。每次改完代码先跑 `node tools/sync-publish.js`（把源码同步到 publish/，并把静态资源版本号换成内容指纹 `?v=<build>`），再用应用发布能力部署 `publish/`。入口链接永久不变，代码一更新资源 URL 自动变化，浏览器必然加载新版本。

## 运行

```bash
node tools/serve.js 8799 .     # 或 python -m http.server 8799
# 打开 http://127.0.0.1:8799/index.html
```

直接双击 `index.html` 也能玩。

## 操作

- `↑↓←→` / `WASD` 走一格（长按连走）；点击格子自动寻路，路上被怪挡住会走过去开打。
- 撞上怪物即战斗（自动演出，可点击跳过）；打不过会被拦住，不会送死。设置里可开「快速战斗」把演出压到 42% 时长。
- 对白：点击 / 空格 / Enter 继续，`←` 上一句，`Esc` 跳过本段。
- 章末锁环三选一：点卡片，或按 `1` / `2` / `3`。
- 触屏：在地图上滑动走一格，连续滑动可连走；右下角虚拟方向键长按连走，点小箭头可收起/展开（默认收起，状态会记住）。
- 层阶之钥：第 4 层可得，点遗物栏的钥匙跳到走过的楼层；**头一次**还能往前开一层，代价是那一层两件最好的东西被封印（锁匠守着的章末层不能绕）。
- 挑战码：通关生成，含层数 / 用时 / 塔印 / 回响章数；把朋友的码贴进名录，就能比谁爬得更高、更快。
- 右上角：🔮 图鉴（买镜后）、🏆 榜单、⚙ 设置（特效/音效/音乐/震动/快速模式/重来本层）。

| 章 | 层 | 主题 | Boss | Boss 层 | 锁 |
|---|---|---|---|---|---|
| 第一章 · 刻痕 | 1–3 | 规矩与计数 | 墨妖（第二位工匠） | 3 | 名册之锁 |
| 第二章 · 明塔 | 4–6 | 真相与代价 | 炎魔 / 魔王（第一位工匠） | 6 | 炉心之锁 |
| 第三章 · 塔脊 | 7–9 | 被删掉的六层 | 钟妖（第五位工匠） | 9 | 时辰之锁 |
| 第四章 · 无名 | 10–12 | 名字的重量 | 碑魔（第六位工匠） | 12 | 无名之锁 |
| 终章 · 锁芯 | 13（隐藏） | 谁来续锁 | —（三精英 + 塔心石） | — | 锁芯 |

- 每位 Boss 都横在该层上楼的**唯一通路**上：叙事上是锁的守护者，玩法上就是那道门闩。
- 第 6 层是旧版塔顶，现在只是中点：打完炎魔，王座后露出窄梯，塔翻到另一半「锁梁」。
- 第 12 层打完碑魔，才能走到公主与隐藏窄梯；击败碑魔后塔顶即开「锁芯」。

详细设计（主题、剧情节点、Boss 放置理由、难度曲线、实现映射）见 [`docs/tower-12-chapters.md`](docs/tower-12-chapters.md)。

## 剧情

- **序章 7 句**：公主被掳进塔、全镇无人敢去；你带着她落下的绣帕，独自推门进塔救人；镇上的人说塔只有六层。中段由墨妖与烛揭开「塔每十年索一条命」的账期，以及她其实是自己来续锁的反转。
- **烛 ×5 段**：1 层（初遇）、4 层（密道）、5 层（狼厅幽灵格）、7 层（锁梁）、11 层（刻名室前）。逐步揭开锁身/锁梁、钟与账期、第六个名字。
- **秤 ×2 段**：第 3 层的军需官；第 8 层留下一副无人货摊。
- **工匠手记**（4 层）：有它才能在塔顶做**显式抉择**。
- **断剑**（5 层）：第八位勇者的遗物，拾取触发旁白，同时是「断刃之锋」。
- **双结局**：「铁与霜」（让她续锁）/「第六个名字」（念出烛的名字）。

## 系统

| 系统 | 说明 |
|---|---|
| 遗物 | 11 件：守誓之盾 / 断刃之锋 / 余烬灯芯 / 鸦的铁腕 / 川的账本 / 岩的灯油 / 无名之镜 / 层阶之钥 / **旧十字架（对亡灵伤害 ×1.5）** / **幸运金币（战斗金币 ×2）**；另有塔心石 |
| 祭坛 | 第 3 / 5 / 8 层各一座「八个人的行李」三选一，一局最多三件；断刃之锋固定在第 5 层狼厅 |
| Boss 战 | 四位章节 Boss（墨妖/炎魔/钟妖/碑魔）各有三阶段过场（66% / 33% 血量），只改表现不改数值 |
| 隐藏层 | 击败碑魔后，塔顶后开窄梯进「锁芯」：三精英 + 塔心石二选一 |
| 路遇 | 每层一个 `?` 点；浅层 6 个 / 中层 6 个 / 深层 8 个事件，共 20 个；部分选择留下通关余烬 |
| 名录 | 塔友榜：三位影子勇者（鸦/岩/川，带死亡层脚注）+ 挑战码贴码进榜，按「爬到多深 → 是否真结局 → 余裕」排序 |
| 余烬 | 通关时按结局、回响、击杀数、决战余裕、塔心等直接累加，只用于解锁誓约与点层灯，不卖战力 |
| 誓约 | 第 2 局起开局四选一（首局先按塔本来的样子走；另两条用余烬解锁），改整局规则；奖励按实测难度序单调排列 |
| 格挡 | 要学的能力（第 2 层盾谱 / 商店 150 金 / 路遇讨教）：每层一次，承伤 ×0.55；后半部盾谱压到 ×0.42，断刃之环再 −0.1 |
| 层阶之钥 | 第 4 层可得；点遗物栏的它，在走过的楼层之间跳（回城补给的核心） |
| 音乐 | 每层一段 4–5 音旋律动机，叠在低频垫音上；设置里「环境音乐」独立开关 |
| 塔心石 | 锁芯中央二选一：带走（生命上限 +300）或放下（通关余烬 +3）；两种后日谈 |
| 章末回响 | 章末 Boss 倒下必得锁环三选一；四章各一枚计入「回响」 |
| 锁环 | 4 章 × 9 枚 = 36 枚，每章随机抽 3 选 1；只改规则/资源/信息（回血、物价、格挡比例、余烬、钥匙、图鉴），不直接加攻防 |
| Boss 台词池 | 每位锁匠的阶段过场每局从 2×2 池里抽一组，同一局固定、换一局不同 |
| 塔印 | 五档（无痕 / 守灯 / 留名 / 未竟 / **折戟**）。前四档由真结局、回响章数、是否回头判定，折戟为死亡专属（不参与最好塔印竞争）；决战余裕另按剩血分 S/A/B/C。**没有结算分** |
| 商店 | 第 3 / 8 / 11 / 13 层各一副货摊（越往上越贵、货架分级）：钥匙、药水、力量训练、护甲强化、盾谱、窥探之镜；攻防训练每次涨价 |
| 怪物特性 | 先攻（必吃一击）/ 魔攻（无视防御）/ 连击（每回合两下）。决定「该加攻还是该加防」：蝙蝠、怨灵、狼人、锈犬、无面者各带其一 |
| 窥探之镜 | 100 金一次性：地图标出每只怪的预计损失，解锁图鉴（含特性标签与「攻+1/防+1 各省多少血」） |
| 成就 | 35 项，localStorage 持久化，吐司通知；图鉴面板内按四区（战斗/收藏/誓约/折戟）陈列，榜单页计数可点击直跳 |
| 软锁兜底 | 每层入口快照，设置里「重来本层」 |
| 快速模式 | 设置独立开关；走路 ×0.65、战斗演出整体压到 42%，另有战斗速度三档独立调节 |
| 存档 | `towermates_save_v3`，`ver:5`；新字段在读取时补默认值，老档继续可用 |

## 核心规则

- 先手战斗：`回合 = ceil(敌HP ÷ (我攻−敌防))`，承伤 `= (回合−1) × max(0, 敌攻−我防)`；守誓之盾再乘 0.88。
- 怪物特性：先攻按 `回合` 次结算（不是 `回合−1`）；魔攻把你防御视作 0；连击每回合两下（`per × 2`）。
- 演出与结算共用 `Engine.fightDamage()`：誓约减伤、停钟之环、格挡只算一次，血条落点与实际扣血一致。
- 攻 ≤ 敌防 → 无法破防；预计承伤 ≥ 当前生命 → 拒绝移动。
- 升级：攻 +3、防 +2、生命 +130（有灯油再 +80），上限 Lv.19，阈值见 `levelExp`。
- 钥匙两色；幽灵格是剧情锚点，不战斗。
- 首次挑战章节 Boss 先播对白，再自动开战；Boss 死亡后播该章收束。
- 第 12 层 Boss 战前记得留格挡（或清够 40 只怪吃满战意）。
