# TowerMates · 魔塔原型 v0.3.2

一个可直接在浏览器里玩的魔塔（固定数值 RPG）原型，带完整剧情与双结局。纯前端、零依赖、数据驱动。

**线上版**：发布目录 `publish/`（只含 index.html + css + js），用应用发布能力部署即可。

## 运行

直接双击 `index.html`，或：

```bash
python -m http.server 8777
# 打开 http://127.0.0.1:8777/index.html
```

操作：`↑↓←→` / `WASD` 移动；撞怪物弹战斗预览，`Enter` 战斗 / `Esc` 离开；对白点击或空格继续（再点一次快进）。

## 剧情（本轮重点）

- **序章**：公主失踪、塔在叫她的名字、你是三百年里第九位勇者。
- **幽灵「烛」×3 段**：造塔工匠的残响，散落在 1/4/6 层，逐步揭示塔的真相。
- **工匠手记**（6 层隐藏）：拿到它才会解锁真结局线。
- **魔王战前对白**：公主不是被抓的，是自己上来续锁的。
- **公主对白 ×2 分支**：有手记 → 真结局「第九个名字」；没有 → 普通结局「铁与霜」。
- **双结局正文**：结算面板按结局显示不同文案。

## 社交（v0.2 轻量版）

- **塔友榜**：右上角 🏆，含 3 个内置影子成绩（三百年里的旧勇者）+ 本机历史记录，按结局 > 层数 > 步数排序。
- **挑战码**：通关后生成，把码发给朋友即可在他的榜单里对比（微信版替换为关系链）。

## 核心规则

- 先手战斗：`回合 = ceil(敌HP ÷ (我攻-敌防))`，承伤 `= (回合-1) × max(0, 敌攻-我防)`。
- 攻 ≤ 敌防 → 无法破防，禁止开战；预计承伤 ≥ 当前生命 → 禁止开战。
- 升级：攻/防 +3、生命 +150，阈值见 `levelExp`。
- 幽灵（🕯️）是剧情锚点，走上即触发对白，不战斗。
- 首次挑战魔王先播对白，再正式开战。
