# TowerMates · 魔塔 v1.7

一个可直接在浏览器里玩的魔塔（固定数值 RPG），6 层主塔 + 1 层隐藏「锁芯」、完整剧情、双结局、七件遗物与三选一祭坛。纯前端、零依赖、数据驱动。

**线上版**：发布目录 `publish/`，用应用发布能力部署即可（只含 index.html + css + js）。

## 运行

```bash
node tools/serve.js 8799 .     # 或 python -m http.server 8799
# 打开 http://127.0.0.1:8799/index.html
```

直接双击 `index.html` 也能玩。

## 操作

- `↑↓←→` / `WASD` 走一格（长按连走）；点击格子自动寻路，路上被怪挡住会走过去开打。
- 撞上怪物即战斗（自动演出，可点击跳过）；打不过会被拦住，不会送死。
- 对白：点击 / 空格 / Enter 继续，`←` 上一句，`Esc` 跳过本段。
- 右上角：🔮 图鉴（买镜后）、🏆 榜单、⚙ 设置（特效/音效/震动/重来本层）。

## 剧情

- **序章 5 句**：灰港镇十年送一人进塔，今年是你。公主同夜失踪。
- **烛 ×3 段**：1 层（进门）、4 层（进密道自动）、5 层（幽灵格），逐步揭开锁环与「魔王」的由来。
- **秤 ×1 段**：第八位勇者的军需官，用买卖赎罪；三十枚铜币由他点破。
- **工匠手记**（4 层）：有它才能在塔顶做**显式抉择**。
- **断剑**（5 层）：第八位勇者的遗物，拾取触发旁白，同时是「断刃之锋」。
- **双结局**：「铁与霜」（让她续锁）/「第六个名字」（念出烛的名字）。

## 系统

| 系统 | 说明 |
|---|---|
| 遗物 | 7 件：守誓之盾（承伤 −12%）/ 断刃之锋（攻 +6）/ 余烬灯芯（击杀回血）/ 鸦的铁腕（攻防 +3）/ 岚的账本（商店 −25%）/ 磐的灯油（升级多 +80 血）/ 无名之镜（直接开图鉴） |
| 祭坛 | 第 3 层随机三选一、第 5 层随机二选一（「八个人的行李」），一局最多两件祭坛遗物 |
| 魔王战 | 三阶段过场（66% / 33% 血量时各一段台词与红光），只改表现不改数值 |
| 隐藏层 | 塔规 ≥5 且击败魔王后，王座后开窄梯进「锁芯」：三精英 + 塔心石，+200 分 |
| 路遇 | 七层各一个 `?` 点；1–3 层出 6 个浅层事件，4 层起换 6 个深层事件（换攻防/换血/换钥匙），共 12 个 |
| 榜单 | 塔友榜按誓约分五档（全部/不立誓/慈悲/贪婪/铁壁），行内标注誓约，结算写明倍率 |
| 誓约 | 开局四选一（不立誓 / 慈悲 / 贪婪 / 铁壁），改整局规则并按难度乘结算分（×0.96 ~ ×1.10） |
| 格挡 | 每层一次：战斗中点一下，这一场承伤 ×0.6；不挡也能通关，但终局只剩 4% 血 |
| 音乐 | 每层一段 4–5 音旋律动机（大调/弗里几亚/布鲁斯…），叠在低频垫音上；设置里「环境音乐」独立开关 |
| 塔心石 | 锁芯中央二选一：带走（生命上限 +300，+200 分）或放下（+320 分）；两种后日谈 |
| 塔规 | 每层一条可选目标（少杀/开门/不花钱/打精英/清层/半血收尾），离开该层时结算，每条 +60 分 |
| 评分 | 结局 + 残血 + 击杀 + 遗物 − 步数/用时/重来次数，S/A/B/C 评级 + 评级尾注 + 战报标签，榜单按分排序 |
| 商店 | 黄/红钥匙、红药水、力量训练、护甲强化、余烬灯芯、窥探之镜；攻防训练每次涨价 20 |
| 窥探之镜 | 100 金一次性：地图标出每只怪的预计损失，解锁图鉴 |
| 成就 | 15 项，localStorage 持久化，吐司通知 |
| 路遇 | 七层各一个 `?` 点；1–3 层出 6 个浅层事件，4 层起换 6 个深层事件（换攻防/换血/换钥匙），共 12 个 |
| 榜单 | 3 个内置影子勇者 + 本机记录 + 挑战码 |
| 软锁兜底 | 每层入口快照，设置里「重来本层」 |
| 存档 | `towermates_save_v3`，带 `ver` 版本号，旧档自动作废 |

## 核心规则

- 先手战斗：`回合 = ceil(敌HP ÷ (我攻−敌防))`，承伤 `= (回合−1) × max(0, 敌攻−我防)`；守誓之盾再乘 0.88。
- 攻 ≤ 敌防 → 无法破防；预计承伤 ≥ 当前生命 → 拒绝移动。
- 升级：攻 +3、防 +2、生命 +130（有灯油再 +80），阈值见 `levelExp`（最高 Lv.9）。
- 钥匙两色；幽灵格是剧情锚点，不战斗。
- 首次挑战魔王先播对白，再自动开战。
