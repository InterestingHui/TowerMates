## v2.4.2：战斗演出掉血节奏修复（commit 5f4ebcc，已推送 + 已部署）

用户反馈：战斗里怪兽扣血扣一会儿，一瞬间血全没了。

根因在 `playBattleScene`：演出刀数有上限（普通怪 5 / Boss 8），真实刀数超过上限时，
旧逻辑「前期每刀按真实伤害打、最后一刀吃掉剩余全部」→ 厚血怪前几刀磨小半条、最后一瞬间清空；
真实刀数更少时 `strikesReal < strikesLeft` 一成立就整条清空 → 速杀怪一闪没了。两条路径都像血蒸发。

修法：**均摊切血**——每刀切 `foeMax/K`，最后一刀收零头，`strikesReal <= 1`（一刀能打死）才直接收。
五场景推演：厚血 180×5 / 速杀 48×3+96 / 一刀秒直接收 / Boss 375×8 / 整除 200×5，全部均匀落底。
