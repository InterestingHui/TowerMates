## 16:21 设置内新增「重置游戏」
- 需求：游戏内加"重置游戏"功能。现有「重来本层」(cfgRetry)、「清空存档」(btnReset，开始页)、「清空存档与成就」(cfgWipe)、「再来一局」(btnAgain，结局页)。缺的是"局内放弃当前一局、从头开始、但保留成就/余烬/解锁"的入口。
- 实现：设置面板(cfgOverlay)操作行加 `🗘 重置游戏` 按钮(id cfgReset)，两步确认防误触（点一下变红"确认重置这一局？"，3.5s 内再点才执行；超时自动还原）。确认后 Sound.stopMotif/setPad(-1) 停音乐，Engine.reset() 清当前局存档（不动 achievements/ember/unlocks），关设置、回开始页、隐藏"继续游戏"、刷新开始页徽章。
- 与「清空存档」区别：后者只清存档不重启、且只在开始页；本按钮局内可达、重置后回到开始页供立即重开。
- 文件：index.html(按钮) / css/style.css(.btn.armed) / js/main.js(状态变量+handler)。已 node --check + tools/check.js + engine-test.js(152 通过) + sync-publish + 提交推送 + 重新部署同一链接，线上实测 index 含 cfgReset、main.js 含 handler。
