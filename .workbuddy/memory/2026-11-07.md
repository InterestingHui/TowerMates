## 真正的 bug（22:09 用户再次反馈后定位）
- 现象：对白每页只显示一个字（"王" / "国" 各占一行）。
- 真因：`story.js` 的 `intro` 是**纯字符串数组**，而 `playStory` 用 `script.map(([who,text])=>...)` 解构。字符串也是可迭代对象，`[who,text]` 把第一个字当说话人、第二个字当台词 → 每页只剩一个字。
- 修法：playStory 兼容两种格式（字符串 = 旁白，数组 = [角色,台词]），空说话人隐藏名字行。
- 连带：给 index.html 的 css/js 加 `?v=0.3.2` 版本号，避免用户浏览器缓存旧 JS。
- 教训：上一轮把「每页一个字」误判为打字机效果，只删了打字机没解决根因。以后遇到"文字异常"先量 DOM 的 textContent，别靠截图猜。
